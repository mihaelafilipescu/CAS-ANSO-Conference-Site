# CAS-ANSO Scientific Conference 2026 Website

Official website for the **CAS-ANSO Scientific Conference 2026**, held in Bucharest, Romania. 

## About the Event
The conference was organized by the **“Ilie Murgulescu” Institute of Physical Chemistry (ICF)** of the **Romanian Academy** with **ANSO** support. It served as a collaborative platform for researchers, scientists, and academics to share findings and discuss advancements in science.

## Tech Stack
* **Framework:** ASP.NET Core
* **Frontend:** HTML5, CSS3, JavaScript / Razor Pages

## Key Features
* **Conference Information & Schedule:** Dedicated pages providing details about the event schedule, program, and committees.
* **Streamlined Submissions & Registrations:** For organizational efficiency and ease of use, the website features an embedded **Google Forms** integration for paper submissions and participant registrations.
* **Responsive Design:** Optimized layout for seamless viewing across desktop and mobile devices.
